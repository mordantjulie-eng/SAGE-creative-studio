# SAGE — Creative Studio · site web

Site vitrine construit avec [Astro](https://astro.build).

## Lancer le site en local
```bash
npm install
npm run dev
```
Puis ouvrir http://localhost:4321

## Où modifier quoi
- **Nom, signature, e-mail, menu, textes des 4 piliers et de la méthode** : `src/config/site.ts`
- **Couleurs, typos, espacements** : `src/styles/global.css` (variables en haut du fichier)
- **Page d'accueil** : `src/pages/index.astro`
- **Logo provisoire** : `src/components/Logo.astro` (à remplacer par le SVG final)
- **Brand book et visuels de référence** : `docs/brand/`
